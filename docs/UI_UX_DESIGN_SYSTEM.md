# BLOOMCRAFT STUDIO — UI/UX DESIGN SYSTEM

**Brand Direction:** Warm Handmade Elegance  
**Target:** Mobile-First for Instagram Shoppers, responsive across tablets and desktops.

## 2. Typography

- **Headings & Display:** `Playfair Display` / `DM Serif Display`
  - Evokes artisanal warmth, editorial charm, and literary elegance.
- **Body & Controls:** `Inter` / `DM Sans`
  - High legibility on mobile screens, crisp numeric rendering for Indian Rupee prices.
- **Scale:**
  - Hero Display: 48px – 60px (h1)
  - Section Headings: 28px – 36px (h2)
  - Card & Feature Titles: 18px – 22px (h3)
  - Body: 14px – 16px, line height 1.6
  - Captions & Microcopy: 11px – 12px

---

## 3. UI Component Patterns

1. **Product Cards:**
   - 1:1 square photo container with rounded 16px corners (`rounded-2xl`).
   - Handmade pill badge in upper left.
   - Quick Add-to-Basket button with clear price display.
2. **Category Cards:**
   - Soft tinted background (`#F6E4EC` / `#EEE9F7`).
   - Circular or rounded image with subtle hover zoom.
3. **Slide-Out Basket Drawer:**
   - Non-intrusive drawer on mobile and desktop.
   - Real-time quantity adjustment and clear item snapshots.
4. **Guest Checkout Form:**
   - Indian delivery address fields with PIN code validation.
   - Transparent delivery calculations and safe payment options.
5. **Admin Operations Queue:**
   - Status badge indicators matching state machines.
   - One-click workflow transitions and manual social channel order recording.
